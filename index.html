I build and run the internal software that factory teams use every day, from the web platform that shows each production line to the Telegram tools staff use to request leave. The work sits where applications, databases, servers and the production floor meet.

  • Leave management system (Python, Flask, Telegram Bot and Mini App) in English and Khmer: staff request leave in Telegram by shift and day or half day; the bot reads written requests, flags duplicates, posts to the team group and edits or removes that post when a request is cancelled.   • Teeth production counter (C#, WinForms, TCP, SQLite): counts parts IN and OUT on a line using two laptops joined by one cable, with no router or internet. The screen compares the shift plan with the live target (green ahead, red behind), switches Day and Night shift by itself, writes an Excel row at each shift change, and repairs its own settings every five minutes. Nothing is lost if the cable is pulled out.
  • Raspberry Pi production counter (Python, Tkinter, GPIO): a separate project from Teeth, tracking production input and output, shift targets and machine stop time.
  • Wrote user guides, admin guides and a video guide so staff can use the tools without asking me.

Coursework and group research

Academic and group work, not commercial products.

    R · 1,145 responses

    Cleaned the survey data and tested what relates to health problems during lockdown. Logistic regression found that more online-class time and more meals a day went with fewer problems. AUC 0.629, a moderate fit.

  • Student stress survey

    202 first-year PSU students
