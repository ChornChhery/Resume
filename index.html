ChatBotRAG — Document Question Answering Chatbot

Personal project · Repository

A full-stack RAG chatbot built with .NET 10, Blazor WebAssembly and SignalR. Upload PDF, TXT or Markdown files and chat with them in real time using local Ollama models — no cloud dependency, full privacy.

  • Built a full-stack web application using Blazor WebAssembly and ASP.NET Core with token-by-token streaming chat via SignalR.
  • Implemented hybrid search (vector + BM25, default 70/30) with source chunks shown under each reply.
  • Moved all embeddings to a Qdrant vector store behind an interface. SQL Server keeps documents, chunk text, chats and messages. An upload writes vectors first; if Qdrant is down, the upload is marked Failed.
  • Supported three chunking strategies (FixedSize, ContentAware, Semantic) with English, Thai and Khmer tokenization.
  • Built a RAG evaluation tab that scores answer quality with BLEU, GLEU, F1 and an LLM Judge. Every run is saved and comparable.
  • Added JWT login with an admin role, and a chat sidebar with pin, rename, delete, and light, dark or system theme.
.NET 10Blazor WebAssemblyASP.NET CoreSignalREF CoreJWT / IdentityOllamaQdrantSQL ServerPdfPigMarkdigDocker Compose
View repository ↗
Full technical record

Upload splits a document into chunks using the selected strategy; each chunk becomes a 1024-dim vector via mxbai-embed-large and is stored in Qdrant. A query embeds the question, runs vector and BM25 search, fuses the scores, retrieves the top passages above the minimum score, and sends them to llama3.2:3b as context. The response streams token by token over SignalR. The evaluation pipeline generates a reference answer from retrieved chunks, generates the RAG answer, compares both with BLEU, GLEU and F1, and adds an LLM Judge score. Pure NLP evaluators are kept separate from DI services and exposed through a REST API. Changing the embedding model requires a new Qdrant collection name and a re-upload.

Full technical record

The backend detects column types, null percentages and the problem type, removes duplicates, fills numeric nulls with the median and categorical nulls with the mode, applies LabelEncoder, and scales numeric features with StandardScaler. It computes descriptive statistics and a Pearson correlation matrix, trains all three models on the full training set, runs k-fold cross-validation, evaluates on a held-out test set, extracts feature importances, and selects the best model by highest CV mean score.
